## Patterns established
- **`mcx claude send` with backticks/braces requires the same `--body-file` workaround as `gh pr create`**: write the message body to a temp file, then `mcx claude send <id> "$(cat /path/to/file)"`. The shell interprets backticks and `${...}` inside double-quoted arguments regardless of the tool being called.
- **Video features: Space key is the right play/pause binding** — context-aware (plays/pauses video when video is active, toggles slideshow otherwise) is a clean pattern that matches macOS media conventions.
- **SlideshowView+Video.swift is now the hot file for video features** — future video issues (zoom/pan, still-frame capture, CIFilter) should coordinate around it the same way image features coordinate around SlideshowView.swift.
