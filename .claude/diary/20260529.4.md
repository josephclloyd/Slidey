- Sprint total cost ~$18 — above the comfortable range for 3 issues. #31 alone was $10.34 for a large new feature.

## Patterns established
- Add `workflow_dispatch` to `build.yml` so CI can be manually triggered — currently impossible without it
- If GitHub Actions stops firing on PR pushes: push a merge commit from main rather than an empty commit or close/reopen
- PRs must include `Closes #N` in body — add this requirement to the impl skill prompt or phase handler
- Sessions in shared checkout are fragile when both touch SlideshowView.swift; enforce worktree isolation in the mcx spawn command
