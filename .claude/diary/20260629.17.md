## Patterns established

- `setDisplay(base:for:)` helper: whenever a new NSImage is committed as the edit result, route through this to automatically compose photo effects. All future edit features should follow this pattern.
- SwiftLint `cyclomatic_complexity` can be suppressed with `// swiftlint:disable:next cyclomatic_complexity` on complex dispatch functions — but extraction is always better if the function can be split cleanly.
- Vision requests: always `DispatchQueue.global(qos: .userInitiated).async` + `DispatchQueue.main.async` for result delivery. Never dispatch on main for the Vision perform() call.
- Photo effect status label in Commands: `@AppStorage("activePhotoEffect")` written by SlideshowView on each `updateDisplayImage()` call; read by `EditMenuCommands` for the label. Works because AppStorage observes UserDefaults KVO — updates propagate without extra wiring.
