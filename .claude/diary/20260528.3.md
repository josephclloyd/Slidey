# Sprint 3 — 2026-05-28

## What was done
- #26 Auto-open recent: show loading state instead of directory picker while images load (PR #30, merged)

## What worked
- Single-issue sprint executed cleanly: impl → review → merge in one session
- Review session correctly fell back to a PR comment when GitHub blocked self-approval
- `isAutoOpening` flag approach was simple and correct — set synchronously before the asyncAfter delay so SwiftUI's first render sees the spinner, not the welcome screen
- Fallback approach (spinner) was the right call; impl session correctly assessed that progressive rendering would require restructuring ImageLoader

## What didn't
- `mcx` binary not on PATH at sprint start — required finding it at `~/.mcp-cli/bin/mcx` and adding `claudeBinary` to `~/.mcp-cli/config.json`
- `claude-for-mcx` symlink pointed to deleted 2.1.128 source dir; fixed by pointing it to the patched binary at `~/.mcp-cli/claude-patched/2.1.128.patched`
- `mcx restart _claude` failed with "server was disconnected and cannot be auto-reconnected" — had to kill mcpd and restart the full daemon (known Sprint 1/2 issue)
- impl session ran in main checkout (not a separate worktree) and left it on the feature branch — had to manually `git checkout main`
- Work item tracking: `prNumber: null` after initial `mcx track 26`; had to untrack + re-track after a 10s delay for the daemon to detect PR #30
- `mcx phase run review` ran silently (empty output file) but did advance the phase; had to run it a second time to get the spawn JSON

## Patterns established
- Set `claudeBinary` in `~/.mcp-cli/config.json` at sprint start — removes the PATH dependency entirely. Add this to pre-flight.
- After impl session goes idle: always check `git branch --show-current` and restore to main before review phase
- Re-track with a 10s delay if `prNumber` is null after initial track — daemon needs time to poll GitHub after PR opens
