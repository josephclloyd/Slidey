## Patterns established

- **Always cd back to the main checkout in the same Bash command as any worktree cd.** The tool persists working directory across invocations; a stale worktree context corrupts subsequent git operations. Pattern: `cd /path/to/worktree && <operations> && cd /Users/joe/Projects/xCode/slidey` — or use absolute paths throughout.
- **Mark sprint container PR ready before attempting mcx pr merge.** Draft PRs silently block `mcx pr merge` with a GraphQL error. Add `gh pr ready <sprint-pr-number>` before the merge step.
- **Quota-hit mid-impl recovery via `mcx claude send`.** When a session goes idle mid-work due to quota, check `mcx claude log <id>` to see what state the work is in, wait for quota reset (check `mcx call _metrics quota_status`), then send a continuation prompt to the idle session with a summary of where it left off. The session resumes from its own context — no need to re-spawn.
