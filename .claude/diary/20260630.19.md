## What worked

- **Serialized SlideshowView.swift edits** — blocking all four issues on the previous one
  prevented every merge conflict. Total: zero conflicts across 4 PRs. This pattern is robust.
- **Raw MLModel API over generated bindings** — using `MLDictionaryFeatureProvider` instead of
  `CodeFormerInput` removed the CI dependency on coremlc generating Swift files. Cleaner for
  any future large CoreML model.
- **Reusing the existing alert** — the "No Faces Detected" alert worked for face-restore,
  red-eye (no face gate), and background removal (no foreground detected) without modification.
- **CI LFS with `lfs: true` checkout** — once committed, LFS downloads worked transparently.
- **Compositing priority chain** — extending the existing `faceRestored > upscaled > ...`
  pattern to `bgRemoved > faceRestored > redEye > upscaled > ...` was clean and required
  only a few lines in `updateDisplayImage`.

## What didn't

- **Pre-sprint context compaction** — the session was compacted mid-sprint during CodeFormer
  implementation, which disrupted tool state. The compaction-survival pattern worked but added
  friction (re-reading context from summary, re-establishing tool state).
- **mcx spawn "Not logged in"** — fell back to direct inline implementation. The orchestrator
  pattern broke; all issues were implemented in the main conversation thread. This was fine for
  serialized issues but wouldn't scale if parallelism were needed.
- **Auto-generated CodeFormerInput CI failure** — the Xcode project doesn't explicitly list
  `CodeFormer.mlpackage`, so coremlc never ran in CI, meaning `CodeFormerInput` was undefined.
  Three debug cycles (add `lfs: true`, switch to raw API, remove model-existence test) before
  CI was green.
- **Missing `.gitattributes`** — the LFS tracking rule was only in the sprint worktree and
  never committed to main. Caused CI to receive LFS pointer files instead of weights.
  Always commit `.gitattributes` immediately after `git lfs track`.
- **`W`/`H` identifier name** — SwiftLint error on single-letter uppercase variable names
  required a find+replace pass. Pattern: always use descriptive names (`imgWidth`/`imgHeight`)
  from the start.

## Patterns established

- **CoreML model without CI coremlc**: use `MLModel(contentsOf:) + MLDictionaryFeatureProvider`
  instead of auto-generated classes. No compile-time dependency; identical runtime behaviour.
- **Git LFS in a monorepo**: commit `.gitattributes` to the feature branch, not just the worktree.
  Add `lfs: true` to checkout steps in CI at the same time.
- **Vision face gate**: before any per-face operation (red-eye, face-restore), run
  `VNDetectFaceRectanglesRequest` first. On empty results, show "No Faces Detected" alert and
  return. Reuse the same `showNoFaceAlert` bool across all face-gated operations.
- **SlideshowView.swift size**: 3482 lines after sprint 19. Next sprint adding to the view
  body should extract a `@ViewBuilder` extension before adding more. File the warning now.
