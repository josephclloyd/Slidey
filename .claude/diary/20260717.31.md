Required manually clearing `review_session_id` via `mcx call _work_items phase_state_delete` and re-running — then still needed a manual `mcx claude spawn` because the second run returned `action: "spawn"` (not `action: "in-flight"`).
- **Bad merge into readme-overhaul**: While trying to unblock a stuck CI build on #295, accidentally pulled in `SlideshowView.swift` changes via `git merge origin/main`. Immediately reverted with `git reset --hard + push --force-with-lease`. The PR was README-only before and after; no feature code was permanently affected.
- **Context compaction mid-sprint**: Session compacted after 4 of 5 issues were near completion, requiring a re-orientation from the summary before proceeding.

## Patterns established

- **Clear `review_session_id` when `pending:` is stuck for more than ~2 minutes** — `mcx call _work_items phase_state_delete '{"workItemId": "#N", "repoRoot": "...", "key": "review_session_id"}'` then re-run the review phase. If the second attempt returns `action: "spawn"` rather than `action: "in-flight"`, execute the spawn command manually.
- **IEEE 754 CGPoint equality in tests**: Use `assertPointEqual` with 1e-10 accuracy tolerance instead of direct `XCTAssertEqual` when the expected value results from addition of non-power-of-2 decimals (e.g., `0.2 + 0.4`).
- **Restore main checkout before each impl**: Always confirm main worktree is on `main` branch before kicking off the next session. Post-impl sessions leave the checkout on the feature branch.
- **`mcx pr merge` over `gh pr merge --auto`**: Re-arms cleanly after force-push; used successfully for all 5 PRs.
