## Patterns established
- **Quota recovery**: when multiple sessions hit quota simultaneously, they make zero progress (no commits, no branches pushed). Clean up the stale local branches (`git branch -D`) immediately so re-spawns start fresh
- **Bundle detection**: if impl session result includes files from another sprint issue, update the PR description to reference both issues (`Closes #N\nCloses #M`) and close the second issue. Don't split unless the bundled change has quality issues
- **`private` visibility review flag**: utility functions extracted to support a UI feature (like `imageDimensions(for:)`) should be `internal`, not `private`, so `@testable import` can reach them in tests. Review sessions now catch this reliably
