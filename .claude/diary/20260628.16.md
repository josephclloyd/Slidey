- Persisting intent (Set of URL strings) instead of NSImage objects for #130 was the right model; re-applying on navigation is seamless

## What didn't

## Patterns established
- `@AppStorage` + `Toggle` in a `CommandGroup` is the canonical pattern for a persisted menu toggle with native checkmark — no notification or manual `NSMenuItem.state` needed
- For persisting filter/enhancement state that is NSImage-backed: persist the URL string set to UserDefaults, re-apply the filter in `updateDisplayImage()` via `DispatchQueue.main.async` with a URL capture list and identity guard
- When implementing directly (no spawned sessions), inline review still catches bugs — don't skip it
