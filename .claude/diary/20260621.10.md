## Patterns established

- When a quota-hit session leaves uncommitted changes, check `git status` immediately — if build passes, commit manually to the session's branch (or create the branch if missing) rather than re-spawning.
- Test-only PRs (no production code) can use `--model sonnet` for review and complete in ~10 turns.
- After a daemon restart, always re-track all sprint work items before spawning sessions.
- Both PRs had `Closes #N` in the body without manual intervention — the impl skill update from Sprint 9 retro is working.
