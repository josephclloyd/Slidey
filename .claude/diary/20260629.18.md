## Patterns established

- **Compositing pipeline order is now fixed**: flip → photo effect → adjustments → vignette. Any new filter step should slot into this chain in the appropriate position in both `updateDisplayImage` and `setDisplay(base:for:)`.
- **HUD pattern**: `showXxxHUD` flag → `updateDisplayImage()` (skips that step) → snapshot `xxxBaseImage = currentDisplayImage` → debounced preview via `Task.sleep(150ms)` → Apply: store + `updateDisplayImage()`; Cancel: clear flag + `updateDisplayImage()`. All three HUDs (Denoise, Vignette, Adjustments) follow this exactly.
- **`Codable` struct for multi-value per-image persistence**: use `JSONEncoder/JSONDecoder` + `UserDefaults.data(forKey:)` rather than storing individual `[String: Double]` dicts per slider. Cleaner for multi-slider HUDs.
- **SwiftLint file_length is now a real constraint**: SlideshowView.swift is at ~3177 lines. The next substantial edit feature should trigger extraction of the HUD functions to a separate extension file with `internal` (not `private`) state vars.
