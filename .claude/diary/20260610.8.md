## Patterns established

- When a session hits quota mid-work: check git status immediately, stash specific files, create correct branch from main, apply stash, strip any cross-contamination from other branches' changes, build-verify, commit, push, create PR manually
- `mcx pr merge --auto` is broken for this repo — use `mcx pr merge --squash` after CI is green
- Two PRs touching project.pbxproj in the same wave will conflict; serialize them or expect a rebase
